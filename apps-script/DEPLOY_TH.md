# CPS PJO Audit — คู่มือติดตั้งบน Google Apps Script (ไม่ต้องมี server)

ระบบนี้รันบน Google ทั้งหมด ข้อมูลเก็บใน Google Sheet และรูป/ลายเซ็นเก็บใน Google Drive ของบัญชีที่ติดตั้ง
ผู้ใช้เปิดผ่านลิงก์เว็บได้ทั้งคอมพิวเตอร์และมือถือ โดยล็อกอินด้วย **ชื่อผู้ใช้ + PIN 6 หลัก** ของระบบเอง ไม่ต้องมีบัญชี Google

> ใช้เวลาติดตั้งประมาณ 15 นาที ทำครั้งเดียว

---

## สิ่งที่ต้องมี

- บัญชี Google 1 บัญชีที่จะเป็น "เจ้าของระบบ" แนะนำให้ใช้บัญชีกลางของแผนก (เช่นบัญชี CPS) แทนบัญชีส่วนตัว เพราะข้อมูลทั้งหมดจะอยู่ใน Drive ของบัญชีนี้
- ไฟล์ในโฟลเดอร์ `dist/` ซึ่งมี 4 ไฟล์

| ไฟล์ | ประเภทใน Apps Script |
|---|---|
| `Code.gs` | Script |
| `Seed.gs` | Script (เป็นมาตรฐาน PJO ทั้ง 7 Workshop ไฟล์ใหญ่ประมาณ 470 KB) |
| `Index.html` | HTML |
| `appsscript.json` | Manifest (ไฟล์ตั้งค่า) |

---

## ขั้นตอนที่ 1 สร้างโปรเจกต์

1. เข้า https://script.google.com ด้วยบัญชีเจ้าของระบบ
2. กด **New project / โครงการใหม่**
3. คลิกชื่อ "Untitled project" ด้านบน แล้วตั้งชื่อเป็น `CPS PJO Audit`

## ขั้นตอนที่ 2 วางไฟล์

1. **Code.gs**: เปิดไฟล์ `Code.gs` ที่มีอยู่แล้วในโปรเจกต์ ลบโค้ดเดิมออกให้หมด แล้ววางเนื้อหาของ `dist/Code.gs` ทั้งไฟล์
2. **Seed.gs**:
   - กด **+** ข้างคำว่า Files แล้วเลือก **Script** ตั้งชื่อ `Seed` (ไม่ต้องพิมพ์ .gs)
   - ลบโค้ดเดิม แล้ววางเนื้อหา `dist/Seed.gs`
   - ไฟล์นี้ใหญ่ หลังวางให้รอสักครู่จนหน้าจอนิ่ง
3. **Index.html**: กด **+** แล้วเลือก **HTML** ตั้งชื่อ `Index` (ตัว I ใหญ่) ลบของเดิม แล้ววางเนื้อหา `dist/Index.html`
4. **appsscript.json**:
   - กดรูปเฟือง ⚙️ **Project Settings** แล้วติ๊ก **"Show 'appsscript.json' manifest file in editor"**
   - กลับมาที่ Editor <> เปิด `appsscript.json` ลบของเดิม แล้ววางเนื้อหา `dist/appsscript.json`
5. กด 💾 **Save** (Ctrl+S)

> ชื่อไฟล์ต้องตรงตามนี้ โดยเฉพาะ `Index` เพราะระบบเรียกหน้าเว็บจากชื่อนี้

## ขั้นตอนที่ 3 ติดตั้งฐานข้อมูล (รัน setup)

1. ในแถบเครื่องมือด้านบน เลือกฟังก์ชัน **`setup`** แล้วกด ▶ **Run**
2. Google จะถามสิทธิ์ ให้กด **Review permissions** เลือกบัญชี
   - ถ้าเจอหน้า "Google hasn't verified this app" ให้กด **Advanced** แล้วกด **Go to CPS PJO Audit (unsafe)**
   - ขึ้นข้อความนี้เพราะเป็นสคริปต์ที่เราเขียนเองและยังไม่ได้ส่งให้ Google ตรวจ ถือเป็นเรื่องปกติ
   - จากนั้นกด **Allow**
   - ระบบขอสิทธิ์แค่ 2 อย่าง คือ Google Sheets และ Google Drive ของบัญชีนี้
3. รอจนรันเสร็จ จะได้ **Execution log** ด้านล่างประมาณนี้

   ```
   ติดตั้งเสร็จ
   ฐานข้อมูล: https://docs.google.com/spreadsheets/d/...
   ...
   บัญชีผู้ดูแลระบบ: admin
   PIN ชั่วคราว: 482913
   ```

4. **จด PIN ชั่วคราวไว้** เพราะจะใช้ล็อกอินครั้งแรก

สิ่งที่ setup สร้างให้ใน Drive ของบัญชีนี้
- Google Sheet ชื่อ **CPS PJO Audit – Data** เป็นฐานข้อมูล ห้ามแก้ไขหรือลบชีตในไฟล์นี้ด้วยมือ
- โฟลเดอร์ **CPS PJO Audit – Files (private)** เก็บรูปถ่ายและลายเซ็น ห้ามแชร์โฟลเดอร์นี้

> ถ้ารัน setup ซ้ำ ระบบจะไม่ลบข้อมูลเดิม แค่เติมส่วนที่ขาด

## ขั้นตอนที่ 4 เผยแพร่เป็นเว็บ (Deploy)

1. กด **Deploy** (มุมขวาบน) แล้วเลือก **New deployment**
2. กดรูปเฟืองข้าง "Select type" แล้วเลือก **Web app**
3. ตั้งค่าดังนี้
   - Description: `v1`
   - **Execute as: Me** (บัญชีเจ้าของระบบ)
   - **Who has access: Anyone**
4. กด **Deploy** แล้ว **คัดลอก Web app URL** (ลงท้ายด้วย `/exec`) ลิงก์นี้คือลิงก์ที่ให้ทุกคนใช้งาน

> ต้องเลือก **Anyone** พนักงานหน้าไลน์จึงเปิดได้โดยไม่ต้องมีบัญชี Google แต่จะเข้าใช้งานจริงได้ต้องมีชื่อผู้ใช้และ PIN ที่ admin สร้างให้เท่านั้น

## ขั้นตอนที่ 5 ตั้งค่าครั้งแรก (ผู้ดูแลระบบ)

1. เปิด Web app URL แล้วล็อกอินด้วย `admin` และ PIN ชั่วคราว ระบบจะบังคับให้ตั้ง PIN ใหม่ 6 หลัก
2. ไปที่เมนู **ผู้ใช้และข้อมูลหลัก**
   - **ทีม**: เพิ่มทีมหรือไลน์ของแต่ละ Workshop
   - **พนักงาน**: เตรียมข้อมูลใน Excel 4 คอลัมน์ `รหัสพนักงาน | ชื่อ-สกุล | Workshop | ทีม` แล้วคัดลอกทั้งตารางมาวางในช่องนำเข้า
   - **ผู้ใช้**: สร้างบัญชีให้ผู้ตรวจ หัวหน้างาน เจ้าของปัญหา และผู้ยืนยัน แล้วกำหนดบทบาทและ Workshop ระบบจะแสดง **PIN ชั่วคราว** ให้ส่งต่อให้เจ้าตัว ซึ่งต้องเปลี่ยน PIN ตอนเข้าครั้งแรก
   - ถ้าผู้ใช้คนนั้นเป็นพนักงานในรายชื่อด้วย ให้ผูกบัญชีกับรหัสพนักงาน เพื่อให้เซ็นด้วยบัญชีตัวเองได้
3. ส่ง Web app URL ให้ผู้ใช้ บนมือถือแนะนำให้กด **"เพิ่มไปยังหน้าจอหลัก" (Add to Home screen)** จะได้ไอคอนเปิดเหมือนแอป

## การอัปเดตเวอร์ชันโดยลิงก์เดิมไม่เปลี่ยน

เมื่อได้ไฟล์ใน `dist/` ชุดใหม่
1. วางทับไฟล์เดิมใน Editor แล้วกด Save
2. ถ้ามีการแก้มาตรฐาน ให้รัน `setup` อีกครั้ง ระบบจะเพิ่มเวอร์ชันใหม่ให้เองโดยข้อมูลเดิมยังอยู่
3. กด **Deploy → Manage deployments** แล้วกดดินสอ ✏️ ที่ deployment เดิม
4. ที่ **Version** เลือก **New version** แล้วกด **Deploy**

ลิงก์ `/exec` เดิมยังใช้ได้ต่อ

> อย่ากด "New deployment" ซ้ำ เพราะจะได้ลิงก์ใหม่ และผู้ใช้ต้องเปลี่ยนลิงก์ทั้งหมด

## ลืม PIN

- **ผู้ใช้ทั่วไปลืม PIN**: admin ไปที่ ผู้ใช้และข้อมูลหลัก แล้วกด **รีเซ็ต PIN** จะได้ PIN ชั่วคราวใหม่
- **admin ลืม PIN**: เปิด Editor เลือกฟังก์ชัน **`resetAdminPin`** แล้วกด Run ดู PIN ชั่วคราวใหม่ได้ใน Execution log
- ถ้าใส่ PIN ผิด 5 ครั้ง บัญชีจะถูกล็อก 15 นาที

## การสำรองข้อมูล

- แนะนำเดือนละครั้ง: เปิด Google Sheet **CPS PJO Audit – Data** แล้วไปที่ File → Make a copy
- Google Sheet มีประวัติเวอร์ชันในตัว ดูได้ที่ File → Version history

## ข้อควรรู้

- **การดาวน์โหลด Excel**: ระบบสร้างไฟล์ Excel ในเบราว์เซอร์ ทดสอบแล้วใช้ได้ แต่เบราว์เซอร์บางตัว (โดยเฉพาะในแอป LINE หรือ in-app browser) อาจบล็อกการดาวน์โหลด ให้เปิดลิงก์ด้วย Chrome หรือ Safari หรือใช้ปุ่ม **พิมพ์** แล้วเลือก "บันทึกเป็น PDF" แทน
- **ใช้งานพร้อมกัน**: บัญชี Gmail ทั่วไปรองรับคนใช้พร้อมกันประมาณ 20–30 คน เพียงพอสำหรับงาน audit ตามแผน ถ้าขึ้นข้อความ "ระบบกำลังบันทึกข้อมูลของผู้อื่น" ให้กดอีกครั้ง
- **สัญญาณหลุดระหว่าง audit**: ระบบเก็บการบันทึกไว้ในเครื่องก่อน แล้วจะ Sync ขึ้นเองเมื่อสัญญาณกลับมา ดูสถานะได้ที่แถบด้านบนของแบบฟอร์ม และอย่าล้างข้อมูลเบราว์เซอร์ก่อน Sync เสร็จ
- **ความปลอดภัย**: อย่าแชร์ Google Sheet หรือโฟลเดอร์ Files ให้คนอื่น ทุกคนควรเข้าผ่านเว็บแอปเท่านั้น เพราะระบบสิทธิ์และ log ทำงานในเว็บแอป
- **ภาระงานของ Google**: ไฟล์รูปถ่าย 1 รูปถูกย่อเหลือประมาณ 200–400 KB พื้นที่ Drive ฟรี 15 GB รองรับรูปได้หลายหมื่นรูป

## แก้ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| เปิดลิงก์แล้วขึ้น "Script function not found: doGet" | ไฟล์ Code.gs ยังไม่ถูกวาง หรือยังไม่ได้ Save ให้วางแล้วอัปเดต deployment (ดูหัวข้อการอัปเดต) |
| ขึ้น "No HTML file named Index" | ไฟล์ HTML ต้องตั้งชื่อ `Index` ตัว I ใหญ่ |
| ขึ้น "ยังไม่ได้ติดตั้งระบบ ให้ผู้ดูแลรันฟังก์ชัน setup ก่อน" | ยังไม่ได้รัน `setup` ด้วยบัญชีเจ้าของระบบ |
| คนอื่นเปิดแล้วต้องขอสิทธิ์ หรือต้องล็อกอิน Google | ตั้ง Who has access เป็น **Anyone** ไม่ใช่ "Anyone with Google account" |
| แก้โค้ดแล้วหน้าเว็บไม่เปลี่ยน | ต้องอัปเดต deployment เป็น New version ทุกครั้ง |
